# Wintabber Dofus - Gestor de Ventanas

**Organiza y gestiona múltiples ventanas de Dofus Retro** sin retrasos ni errores de mouse.  
Encapsula cada ventana, evitando que el cursor se descontrole perdiendo registro de clicks un problema común en apps como WindowTabs.

## Características

- Captura automática de ventanas
- Pestañas para todas las cuentas
- Drag & Drop para reorganizar
- Redimensionamiento automático
- Guardar layouts (F4) / Cargar layouts (F5)
- Gestor de layouts (F6)
- Acceso rápido a layouts: Ctrl+Alt+1..9

## Atajos de Teclado

| Tecla | Función |
|-------|---------|
| F1    | Ventana anterior |
| F2    | Ventana siguiente |
| F3    | Mostrar/Ocultar menú |
| F4    | Guardar layout |
| F5    | Cargar layout |
| F6    | Abrir gestor de layouts |
| Ctrl+Alt+1..9 |  Cambiar a pesta;a directamente (Principalmente usado para compatibilidad con Dofus Tools |

## Instalación y Uso

1. Descarga el ejecutable desde [Releases](../../releases)  
2. Ejecuta `WintabberDofus.exe`  
3. Presiona **"⚡ CAPTURAR VENTANAS"**  
4. Usa F1/F2 Para cambiar entre ventanas

## Requisitos

- Windows 10/11 (64-bit)  
- .NET 4.7.2+  
- 2 GB RAM  
- 50 MB de espacio  

Recomendado: Windows 11, .NET 6.0+, 4 GB RAM
